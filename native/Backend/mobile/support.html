Files and transfers

Keep the app open during transfers. To resume a paused upload, select the same original file. Use Restore and Share to export a cloud file to Files or another app. Data Saver reduces concurrent transfers on constrained connections.

Account and privacy

Sign in with the Google account used for your workspace. For access, correction or deletion requests, contact the address above. Never send passwords, payment card details or API secrets.

Billing

Use Manage Billing in the web or desktop app for existing Stripe subscriptions. Include your account email and a description of the issue when contacting support.
